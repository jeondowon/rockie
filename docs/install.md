# Rockie 설치 안내

최종 수정일: 2026-08-22
대상: macOS 12(Monterey) 이상 · Apple Silicon(M1 이후)

---

## 1. 설치

1. [다운로드 페이지](https://jeondowon.com/rockie)에서 `Rockie-x.x.x-arm64.dmg`를 내려받습니다.
2. 받은 파일을 두 번 눌러 엽니다.
3. 나타난 창에서 **Rockie를 `응용 프로그램` 폴더로 끌어다 놓습니다.**
4. `응용 프로그램` 폴더에서 Rockie를 실행합니다.

Rockie는 Apple에 등록된 개발자 ID로 서명·공증되어 있으므로, 실행할 때 보안 경고가 뜨지 않습니다.

> **Intel Mac은 아직 지원하지 않습니다.** 현재 배포 파일은 Apple Silicon 전용입니다.

---

## 2. Dock에 아이콘이 없습니다

Rockie는 **화면 상단 메뉴 막대에만 상주하는 앱**입니다. 실행해도 Dock에는 아이콘이 나타나지 않고, `Cmd+Tab` 목록에도 잡히지 않습니다. 고장이 아니라 의도된 동작입니다.

- 앱의 모든 기능은 **화면 상단 메뉴 막대의 Rockie 아이콘**을 눌러 사용합니다. 메뉴 막대에 항목이 많으면 아이콘이 왼쪽으로 밀려 있거나 가려져 있을 수 있습니다.
- 애완돌 자체는 화면 위에 떠 있으며, 두 번 누르면 모드 선택 창이 열립니다.
- Launchpad에는 표시되므로 거기서 실행하셔도 됩니다.

이렇게 만든 이유는 애완돌이 **전체 화면 앱 위에도 보여야 하기** 때문입니다. macOS에서 두 가지를 동시에 만족시킬 수 없어 Dock 아이콘을 포기했습니다.

---

## 3. 권한 안내

Rockie는 macOS 권한 세 가지를 사용합니다. **셋 다 허용하지 않아도 애완돌은 정상적으로 동작합니다.** 각 권한은 특정 기능 하나씩에만 연결되어 있습니다.

| 권한 | 언제 요청하나 | 쓰이는 곳 | 허용하지 않으면 |
| --- | --- | --- | --- |
| 화면 기록 | 첫 실행 안내 중 | 지금 쓰고 있는 앱을 알아채고 그에 맞는 말풍선 표시 | 앱에 맞춘 말풍선만 나오지 않습니다 |
| 자동화 | 첫 실행 안내 중 (선택) | Dock의 위치 읽기 | 애완돌이 Dock에 겹칠 수 있습니다 |
| 손쉬운 사용 | Dock을 처음 읽을 때 · 쪽잠 · 청소 모드를 처음 켤 때 | Dock의 위치 읽기 · 키보드 잠금 | 애완돌이 Dock에 겹칠 수 있고, 해당 모드에서 키보드가 잠기지 않습니다 (알람은 그대로 울립니다) |

### Dock 회피에 권한이 두 개 필요한 이유

Dock의 위치를 읽는 일은 한 줄짜리 명령이지만 macOS 안에서는 두 단계로 나뉩니다.

1. Rockie가 macOS의 `System Events`에게 "Dock이 어디 있는지 봐 달라"고 부탁합니다 → **자동화**
2. `System Events`가 Dock의 화면 요소를 실제로 읽습니다 → **손쉬운 사용**

2단계에서 macOS는 심부름을 한 `System Events`가 아니라 **처음 시킨 Rockie에게** 권한이 있는지 봅니다. 공용 도구를 방패 삼아 권한을 우회하지 못하게 막아둔 것입니다. 그래서 자동화만 허용하면 1단계는 통과하고 2단계에서 막힙니다.

둘 다 허용하지 않으셔도 애완돌은 정상 동작하며, Dock을 피하는 정확도만 떨어집니다.

### "화면 기록" 권한이 걱정되신다면

macOS는 **다른 앱의 창 제목을 읽는 것**과 **화면을 촬영하는 것**을 같은 권한으로 묶어 두었습니다. Rockie는 앞의 것만 필요해서 이 권한을 요청하며, **화면을 촬영하거나 저장하지 않습니다.**

읽어들인 창 제목은 어떤 말풍선을 띄울지 고르는 데에만 쓰이고, 화면에 표시되지도 기록되지도 않습니다. 메신저·금융·인증 화면에서는 아예 말풍선을 띄우지 않습니다. 자세한 내용은 [개인정보처리방침](https://jeondowon.com/rockie/privacy)을 참고해 주세요.

### 권한을 허용했는데 반영되지 않을 때

**앱을 완전히 종료했다가 다시 실행해 주세요.** macOS는 실행 중인 앱에 권한을 바로 적용하지 않습니다. 메뉴 막대 아이콘 → **종료**로 끈 뒤 다시 실행하시면 됩니다.

### 나중에 권한을 바꾸려면

메뉴 막대 아이콘 → **설정 → 권한**에서 현재 상태를 확인하고 시스템 설정을 바로 열 수 있습니다.

macOS의 **시스템 설정 → 개인정보 보호 및 보안**에서 직접 바꾸셔도 됩니다.

손쉬운 사용 목록에는 항목이 **두 개** 나타납니다. 하는 일이 달라 따로 잡혀 있습니다.

- **`Rockie`** — Dock의 위치를 읽습니다. 끄면 애완돌이 Dock에 겹칠 수 있습니다.
- **`KeyBlocker`** — 쪽잠 · 청소 모드에서 키보드를 잠급니다. 키보드를 잠그는 기능만 별도 프로그램으로 분리해 두었습니다.

## 4. 업데이트

Rockie는 새 버전을 **자동으로 확인하고 내려받습니다.** 다 받으면 알림이 한 번 뜨고, 메뉴 막대 메뉴에 **"업데이트 설치 후 재시작"** 항목이 나타납니다.

- 그 항목을 누르면 즉시 새 버전으로 교체되고 앱이 다시 켜집니다.
- 누르지 않으셔도 다음에 앱을 껐다 켤 때 자동으로 적용됩니다.
- 인터넷에 연결되어 있지 않으면 조용히 넘어가고, 나중에 다시 확인합니다.

현재 버전은 **설정 화면 맨 아래**에서 확인하실 수 있습니다.

---

## 5. 삭제

1. 메뉴 막대 아이콘 → **종료**로 앱을 끕니다.
2. `응용 프로그램` 폴더에서 Rockie를 휴지통으로 옮깁니다.

저장된 애완돌 정보까지 완전히 지우시려면 아래 폴더를 함께 삭제해 주세요.

```
~/Library/Application Support/Rockie/
```

Finder에서 `Shift+Cmd+G`를 누르고 위 경로를 붙여 넣으면 바로 이동할 수 있습니다.

시스템 설정 → 개인정보 보호 및 보안에서 `Rockie`와 `KeyBlocker` 항목도 함께 지우시면 깔끔합니다.

> 앱을 지우지 않고 **처음부터 다시 키우고** 싶으시다면, 설정 화면의 "↻ 처음부터 다시 키우기"를 누르시면 됩니다.

## 6. 문제가 있을 때

| 증상 | 확인할 것 |
| --- | --- |
| 애완돌이 안 보입니다 | 메뉴 막대 아이콘 → "애완돌 숨기기 / 보이기"가 숨김 상태일 수 있습니다 |
| 앱에 맞는 말풍선이 안 나옵니다 | 화면 기록 권한을 허용한 뒤 **앱을 재시작**했는지 확인해 주세요 |
| 애완돌이 Dock에 겹칩니다 | 자동화 권한을 허용해 주세요 (설정 → 권한) |
| 쪽잠 모드에서 키보드가 안 잠깁니다 | 손쉬운 사용에서 **`KeyBlocker`** 를 켜고 앱을 재시작해 주세요 |
| 메뉴 막대에서 아이콘을 못 찾겠습니다 | 항목이 많으면 화면 밖으로 밀려 보이지 않을 수 있습니다. 다른 아이콘을 정리하거나 Bartender 같은 도구로 확인해 보세요 |
