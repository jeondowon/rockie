# 장식 위치와 크기 조정

설정은 `src/renderer/shared/attachments.js`에 있습니다. 실제 펫과 상점 미리보기가 같은 계산을 사용합니다. 상점은 현재 캐릭터의 웃는 표정으로 미리보기를 표시합니다.

- `CHARACTER_ATTACHMENTS`: 캐릭터별 장착 영역. `head`는 머리 위, `side`는 머리 옆, `body`는 몸 중심입니다. 각 영역의 `x`, `y`, `width`를 지정합니다.
- `ITEM_ATTACHMENTS`: 아이템의 장착 영역(`slot`), 붙는 지점(`x`, `y`), 그림 너비(`width`), 장착 영역 대비 너비 비율(`scale`)입니다.
- `CHARACTER_ITEM_ATTACHMENTS`: 특정 캐릭터·아이템 전용 기준점입니다. 등록된 조합은 공통 장착 영역 대신 이 값을 사용합니다. `rockie`의 `leaf-sprout`(새싹)은 다른 아이템과 독립적으로 조정됩니다.
- 좌표와 너비는 모두 **320×320 캔버스 기준**입니다. 장식 SVG의 `viewBox`가 80×80이면 SVG 좌표에 4를 곱해 기록합니다.

장식의 표시 너비는 `적용되는 기준점의 width × 아이템 scale`입니다. 두 기준점을 맞춘 뒤 펫 표시 크기에 맞춰 함께 확대·축소합니다. 캐릭터 머리 너비를 바꾸면 전용 기준점이 없는 머리 장식이 함께 조정됩니다. 특정 아이템이 모든 캐릭터에서 크거나 작다면 그 아이템의 `scale`을 변경합니다.

## 실시간 튜너 사용

1. `src/renderer/pet/pet.js`의 `PREVIEW`를 다음처럼 설정합니다.

   ```js
   const PREVIEW = {
     level: "level0",
     prefix: "rockie",
     item: "tiny-crown",
   };
   ```

2. `npm run dev`로 실행하고 앱 창에 키보드 포커스를 줍니다. 실제 보유·장착 정보는 바뀌지 않으며, 미보유 장식도 미리볼 수 있습니다.

   | 키 | 동작 |
   |---|---|
   | 방향키 | 현재 장착 영역 기준점 이동 |
   | `-` / `=` | 장착 영역 너비 축소 / 확대 |
   | `Shift` + 방향키·너비 키 | 10px씩 조정 (기본 1px) |
   | `[` / `]` | 이전 / 다음 캐릭터 |
   | `,` / `.` | 이전 / 다음 장식 |
   | `S` | 펫 크기 전환 |
   | `T` | 하트 → 말풍선 → 장식 조정 전환 |
   | `C` | 현재 대상의 설정을 클립보드에 복사하고 콘솔에도 출력 |

   아이템을 바꾸면 그 아이템이 사용하는 **캐릭터의 공통 장착 영역**을 조정합니다. 화면 좌상단에는 공통 기준점의 좌표와 너비가 표시됩니다. 전용 기준점이 있는 조합도 키보드로는 공통 기준점을 편집하므로, 해당 장식의 실제 배치에는 변경이 반영되지 않습니다. 예를 들어 `rockie`의 `leaf-sprout`은 아래의 개별 튜닝 방식으로 조정합니다.

3. 장식 모드에서 `C`를 누르면 `CHARACTER_ATTACHMENTS`만 복사됩니다. `attachments.js`의 해당 선언을 교체합니다. **파일을 저장해 새로고침하기 전에 값을 복사해야 합니다.** 튜닝 값은 실행 중 메모리에만 있고 자동 저장되지 않습니다. 하트·말풍선 모드에서 복사한 값은 기존처럼 `pet-data.js`에 붙여넣습니다.

4. 작업이 끝나면 `PREVIEW`를 `null`로 되돌립니다.

## 캐릭터·아이템별 개별 튜닝

특정 조합만 조정하려면 `attachments.js`의 `CHARACTER_ITEM_ATTACHMENTS`를 직접 수정합니다. 예를 들어 `rockie`의 `leaf-sprout` 항목에서 `x`, `y`는 위치를, `width`는 크기를 조정합니다. 새 조합을 추가할 때는 해당 캐릭터의 공통 장착 영역 값을 복사해 시작할 수 있습니다.

`PREVIEW`를 확인할 캐릭터·아이템으로 설정하고 `npm run dev`에서 파일을 저장하면 새로고침 후 결과를 볼 수 있습니다. 전용 기준점은 공통 기준점보다 우선하며, 다른 캐릭터·아이템의 배치에는 영향을 주지 않습니다. 전용 기준점은 튜너의 `C` 복사 대상에 포함되지 않습니다.

전용 기준점이 없는 아이템은 캐릭터의 장착 영역을 공유합니다. 표정별·애니메이션 프레임별로 따로 추적하지는 않습니다.
