# 릴리스 노트

사용자에게 보이는 변경사항을 버전별로 정리한다. 최신 버전이 위에 온다.

`scripts/release.sh`가 현재 버전의 절(`## 1.0.2` 같은 제목부터 다음 제목 전까지)을
잘라 GitHub 릴리스 본문으로 올린다. **제목 형식을 바꾸면 릴리스 본문이 비어버린다.**

---

## 1.0.2

2026-08-21

### 새로 추가된 것

- 설정 화면 아래쪽에 **개인정보처리방침 · 이용약관 · 오픈소스 라이선스 · 문의** 링크가 생겼습니다. 누르면 기본 브라우저로 열립니다.
- 설정 화면에 **현재 앱 버전**이 표시됩니다. 이전에는 실제 버전과 상관없이 항상 "v1"로 보였습니다.
- Rockie에 포함된 오픈소스 소프트웨어의 저작권 고지가 앱에 함께 담겼습니다. 앱을 우클릭 → "패키지 내용 보기" → `Contents/Resources`에서 볼 수 있고, 웹에서는 [오픈소스 라이선스](https://jeondowon.com/rockie/licenses) 페이지에 있습니다.

### 알아두실 점

- 개인정보처리방침에 **자동 업데이트 확인 시 GitHub 서버에 접속한다는 점**을 명시했습니다. 동작이 바뀐 것은 아니고, 1.0.1부터 있던 통신을 문서로 밝힌 것입니다. 앱은 여전히 이용자의 정보를 수집하거나 전송하지 않습니다.
- Rockie의 소스 코드가 [GitHub](https://github.com/jeondowon/rockie)에 MIT 라이선스로 공개되어 있습니다. 캐릭터와 이미지는 저작권을 유보합니다.

기능 동작에는 변화가 없습니다.

## 1.0.1

2026-08-21

### 버그 수정

- **Dock을 자동으로 숨기는 설정에서 애완돌이 100px가량 떠 있던 문제**를 고쳤습니다. Dock 아이콘 크기를 실제보다 크게 계산하고 있었습니다.
- 자동화 권한을 거부하면 애완돌이 Dock을 피하지 못하는데도 아무 안내가 없던 문제를 고쳤습니다. 이제 설정 화면에 안내가 뜹니다.
- 프롤로그 도중 맥락 없이 권한 요청 창이 뜨던 문제를 고쳤습니다.
- 프롤로그에서 운석이 떨어진 뒤 언어를 바꾸면 화면이 멈추던 문제, 질문 화면에서 언어를 바꿔도 문구가 그대로이던 문제를 고쳤습니다.
- 영어에서 선택지 네 번째 항목이 잘리던 문제를 고쳤습니다.
- 모드 선택 창이 `[object Object]`로 표시되던 문제를 고쳤습니다.
- 트레이 설정 화면의 구분선과 행 너비가 어긋나던 문제를 고쳤습니다.

### 변경

- 온보딩에서 **손쉬운 사용 권한을 묻지 않습니다.** Rockie 본체에는 필요하지 않고, 쪽잠 모드의 키보드 잠금은 그때 따로 요청합니다.
- 대신 **자동화 권한**을 선택 항목으로 안내합니다. Dock 위치를 읽는 데 쓰이며, 허용하지 않아도 나머지 기능은 그대로 동작합니다.

## 1.0.0

2026-08-20

첫 공개 릴리스입니다.

- 화면 위에 사는 데스크톱 애완돌. 마우스를 따라다니고, 클릭에 반응하고, Dock을 피해 다닙니다.
- 매일 오는 성향 질문에 답하면 조약돌이 **화강암·현무암·대리석·편마암** 중 하나로 확정되고, 이후 변성체를 거쳐 보석으로 진화합니다.
- 사용 중인 앱과 시간대에 맞춰 말풍선을 띄웁니다. 메신저·금융·인증 화면에서는 아무 말도 하지 않습니다.
- 청소 · 집중 · 쪽잠 · 발표 모드.
- 트레이에서 CPU · 메모리 · 디스크 · 배터리 · 네트워크 상태를 볼 수 있는 시스템 모니터.
- 한국어 · 영어 지원.
- 자동 업데이트.
