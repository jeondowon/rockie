# Rockie 개인정보처리방침

최종 수정일: 2026-08-21
적용 버전: Rockie 1.0.1 이상

Rockie(이하 "앱")는 개인 개발자 jeondowon이 무료로 제공하는 macOS 데스크톱 앱입니다. 이 방침은 앱이 어떤 정보를 다루고, 그 정보가 어디에 머무는지 설명합니다.

---

## 1. 핵심 요약

- **앱은 개인정보를 수집하지 않으며, 이용자의 정보를 담은 서버를 운영하지 않습니다.**
- 앱이 다루는 모든 정보는 이용자의 Mac 안에서만 처리되고 저장됩니다.
- 광고 SDK, 분석 SDK, 이용 통계 수집 도구를 일절 사용하지 않습니다.
- 외부로 나가는 통신은 **자동 업데이트 확인 한 가지**뿐이며, 그 내용은 5항에 적었습니다.

---

## 2. 기기 안에 저장되는 정보

아래 정보는 이용자의 Mac에 있는 다음 파일 한 곳에만 저장됩니다.

```
~/Library/Application Support/Rockie/petdata.json
```

| 항목 | 사용 목적 |
| --- | --- |
| 이용자가 입력한 이름 | 말풍선 메시지 개인화 |
| 애완돌 이름 | 화면 표시, 호감도 보상 |
| 성향 질문 답변 | 돌 종류 판정과 진화 단계 결정 |
| 진화 단계·호감도·스킨 상태 | 앱 상태 유지 |
| 앱 설정 (자동 실행, 효과음, 펫 위치·크기, 집중/쪽잠 시간, 표시 언어 등) | 설정 유지 |
| 최초 설치 시각, 온보딩 완료 여부 | 첫 실행 안내 표시 여부 판단 |

이 파일은 이용자 본인의 계정 폴더에 있는 일반 파일이며, 앱이 외부로 보내지 않습니다.

---

## 3. 저장하지 않고 그 순간에만 읽는 정보

아래 정보는 화면에 반응을 표시하기 위해 실행 중에만 읽고, **파일에 기록하거나 전송하지 않습니다.** 앱을 끄면 사라집니다.

| 항목 | 사용 목적 |
| --- | --- |
| 현재 활성화된 앱의 이름과 창 제목 | 사용 중인 앱에 맞는 말풍선 표시 |
| 마지막 입력 이후 경과 시간(idle time) | 자리를 비웠을 때의 반응 |
| 현재 시각 | 시간대별 반응 |
| CPU·메모리·디스크·배터리·네트워크 사용량 | 메뉴 막대의 시스템 모니터 화면 표시 |
| Dock의 위치와 크기 | 애완돌이 Dock을 피해 다니도록 계산 |
| 화면 기록 권한 허용 여부 | 기능 사용 가능 여부 안내 |

**창 제목에 대한 추가 설명**

활성 창 제목에는 문서 이름이나 웹페이지 제목처럼 사적인 내용이 담길 수 있습니다. 이에 대해 앱은 다음과 같이 동작합니다.

**창 제목은 화면에 표시되지 않습니다.** 앱은 창 제목을 미리 정해둔 조건과 대조해 어떤 말풍선을 띄울지 고르는 데에만 사용합니다. 말풍선에 나오는 문구는 앱에 내장된 고정 문장이며, 읽어들인 창 제목이 그대로 화면에 나타나는 경로는 없습니다.

**아래 영역에서는 말풍선을 아예 띄우지 않습니다.**

- 카카오톡, 메일 앱
- 은행, 카드, 증권, 가상자산 거래소
- 병원, 정부·민원 서비스
- 비밀번호 관리자, 인증 앱, 로그인·인증 화면

다만 Slack·Discord·Microsoft Teams 등 업무용 협업 도구에서는 "누가 불렀나 봐요" 수준의 일반적인 말풍선이 표시될 수 있습니다. 이 경우에도 대화 내용이나 창 제목은 표시되지 않습니다.

---

## 4. 시스템 권한

앱은 macOS 권한 세 가지를 사용할 수 있습니다. 모두 **허용하지 않아도 기본 기능은 그대로 동작합니다.**

| 권한 | 쓰이는 곳 | 허용하지 않으면 |
| --- | --- | --- |
| 화면 기록 | 활성 앱 이름과 창 제목 읽기 | 앱별 말풍선만 표시되지 않습니다 |
| 자동화 (System Events) | Dock의 위치·크기 읽기 | 애완돌이 Dock을 피하지 못할 수 있습니다 |
| 손쉬운 사용 | 쪽잠·청소 모드의 키보드 잠금 | 해당 모드에서 키보드가 잠기지 않습니다 |

macOS의 "화면 기록" 권한은 이름과 달리 **화면을 촬영하거나 녹화하기 위한 것이 아닙니다.** 다른 앱의 창 제목을 읽으려면 macOS가 이 권한을 요구하기 때문에 사용합니다. 앱은 화면을 캡처하지 않습니다.

---

## 5. 외부로 나가는 통신 — 자동 업데이트

앱은 새 버전이 있는지 확인하기 위해 **GitHub Releases**(github.com)에 접속합니다.

- 접속 시점: 앱 시작 1분 후, 이후 6시간마다
- 보내는 내용: 새 버전 정보 파일을 요청하는 일반적인 웹 요청입니다. 앱은 이용자의 이름, 애완돌 정보, 사용 기록 등 어떤 개인정보도 이 요청에 담지 않습니다.
- 다만 인터넷 통신의 성격상 **GitHub 서버에는 이용자의 IP 주소, 접속 시각, 요청한 파일 정보가 남을 수 있습니다.** 이는 GitHub의 개인정보처리방침에 따라 처리되며, 개발자는 이 기록에 접근할 수 없습니다.
  - GitHub 개인정보처리방침: https://docs.github.com/site-policy/privacy-policies/github-privacy-statement

이 통신을 원하지 않으시면 macOS 방화벽에서 앱의 외부 접속을 차단하셔도 됩니다. 업데이트 확인만 실패하고 나머지 기능은 정상 동작합니다.

이 외에 설정 화면의 링크 버튼을 누르면 기본 웹 브라우저로 해당 페이지가 열립니다. 이는 이용자가 직접 누른 경우에만 발생합니다.

---

## 6. 제3자 제공

앱은 이용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 애초에 개발자에게 전달되는 정보 자체가 없습니다.

---

## 7. 정보의 보관과 삭제

앱이 저장하는 정보는 이용자의 Mac에만 있으므로, 삭제 권한도 전적으로 이용자에게 있습니다.

**앱 안에서 지우기**
메뉴 막대 아이콘 → 설정 → "처음부터 다시 키우기"를 누르면 저장된 진행도·성향·호감도·설정이 모두 지워지고 초기 상태로 돌아갑니다.

**완전히 지우기**
앱을 삭제하신 뒤 아래 폴더를 함께 지우시면 남는 데이터가 없습니다.

```
~/Library/Application Support/Rockie/
```

시스템 설정 → 개인정보 보호 및 보안에서 Rockie에 부여한 권한도 함께 해제하실 수 있습니다.

---

## 8. 아동의 개인정보

앱은 이용자로부터 개인정보를 수집하지 않으므로 연령을 확인하지 않으며, 아동의 개인정보를 수집하지 않습니다.

---

## 9. 방침의 변경

기능이 추가되어 다루는 정보가 달라지면 이 방침을 수정하고, 문서 상단의 최종 수정일을 갱신합니다. 중요한 변경이 있을 경우 앱의 릴리스 노트에 함께 안내합니다.
